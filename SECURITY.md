# Security Policy

## Supported Versions

Versions currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |


## Reporting a Vulnerability

Please report all detected vulnerabilities to ticketgoat-security@jagoan.es marking your email with the following subject TG-SECURITY[HIGH-MEDIUM-LOW]:[Vulnerability description]

You can expect an update within a day, we unfortunately will not be compensating for vulnerability reporting with money due to funding restrictions, but we deeply appreciate all findings being reported.
